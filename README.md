# NutriVibe — Nutrition & Diet Blog[cite: 2]

A modern, fully responsive website dedicated to healthy eating, a balanced lifestyle, and nutritious recipes[cite: 2]. The project is developed using vanilla JavaScript for dynamic interface generation, styled with Bootstrap 5, and enhanced with custom CSS[cite: 2].

---

## 🚀 Key Features

* **Dynamic DOM Generation:** The entire page structure (navigation, menus, blog card grid) is created programmatically using a universal custom creator function[cite: 2].
* **Responsive Design:** The site displays correctly across all devices (from smartphones with a 320px screen width to large desktops) thanks to the Bootstrap grid system and custom @media queries[cite: 2].
* **Interactive Navigation:**
  * User-friendly menu with a dropdown list (Pages)[cite: 2].
  * Mobile slide-out menu (hamburger menu with FontAwesome icons), optimized for screens smaller than 992px[cite: 2].
* **Blog Cards:**
  * Dynamic rendering of blog articles from data arrays[cite: 2].
  * Fixed card height (h-100) and adaptive images (object-fit: cover), ensuring a clean, uniform look for all blocks[cite: 2].
* **Interactive Elements:** Smooth hover animations, button effects, and a cart/items counter[cite: 2].

---

## 🛠️ Technologies Used

* **HTML5** — Content structure[cite: 2].
* **CSS3 / Flexbox** — Custom styles, animations, and responsive media queries[cite: 2].
* **JavaScript (ES6)** — Dynamic element creation and rendering logic[cite: 2].
* **Bootstrap 5** — Layout grid, ready-to-use utility classes for containers, columns, and spacing[cite: 2].
* **FontAwesome** — Icons for navigation and the shopping cart[cite: 2].

# NutriVibe — Nutrition & Diet Blog

Современный и полностью адаптивный веб-сайт, посвященный правильному питанию, здоровому образу жизни и полезным рецептам. Проект разработан с использованием чистого **JavaScript** для динамического создания интерфейса, стилизован с помощью **Bootstrap 5** и кастомных **CSS**-стилей.

---

## 🚀 Основные особенности

* **Динамическая генерация DOM:** Вся структура страницы (навигация, меню, сетка карточек с блогами) создается программно с помощью универсальной кастомной функции `creator`.
* **Адаптивный дизайн (Responsive):** Сайт корректно отображается на любых устройствах (от смартфонов с шириной экрана 320px до широких экранов ПК) благодаря сетке Bootstrap и кастомным медиа-запросам (`@media`).
* **Интерактивная навигация:**
  * Удобное меню с выпадающим списком (`Pages`).
  * Мобильное выдвижное меню (гамбургер-меню с иконкой FontAwesome), адаптированное под экраны менее 992px.
* **Блог-карточки:**
  * Динамический вывод карточек со статьями из массивов данных.
  * Фиксированная высота карточек (`h-100`) и адаптивные изображения (`object-fit: cover`), обеспечивающие аккуратный и одинаковый размер блоков.
* **Интерактивные элементы:** Плавные анимации при наведении (`hover`), эффекты кнопок и счетчик товаров/корзины.

---

## 🛠️ Используемые технологии

* **HTML5** — структурирование контента.
* **CSS3 / Flexbox** — кастомные стили, анимации и адаптивные медиа-запросы.
* **JavaScript (ES6)** — динамическое создание элементов интерфейса и логика рендеринга данных.
* **Bootstrap 5** — сетка, готовые классы для контейнеров, колонок и отступов.
* **FontAwesome** — иконки для навигации и корзины.
