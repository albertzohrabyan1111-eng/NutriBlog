# NutriVibe — Nutrition & Diet Blog

Современный и полностью адаптивный веб-сайт, посвященный правильному питанию, здоровому образу жизни и полезным рецептам. Проект разработан с использованием чистого **JavaScript** для динамического создания интерфейса, стилизован с помощью **Bootstrap 5** и кастомных **CSS**-стилей.

---

## 🚀 Основные особенности

* **Динамическая генерация DOM:** Вся структура страницы (навигация, меню, сетка карточек с блогами) создается программно с помощью универсальной кастомной функции `creator`.
* **Адаптивный дизайн (Responsive):** Сайт корректно отображается на любых устройствах (от смартфонов с шириной экрана 320px до широких экранов ПК) благодаря сетке Bootstrap и кастомным медиа-запросам (`@media`).
* **Интерактивная навигация:**
  * Удобное меню с выпадающим списком (`Pages`).
  * Мобильное выдвижное меню (гамбургер-меню с иконкой FontAwesome), адаптированное под экраны менее 992px.
* **Блог-карточки:**
  * Динамический вывод карточек со статьями из массивов данных.
  * Фиксированная высота карточек (`h-100`) и адаптивные изображения (`object-fit: cover`), обеспечивающие аккуратный и одинаковый размер блоков.
* **Интерактивные элементы:** Плавные анимации при наведении (`hover`), эффекты кнопок и счетчик товаров/корзины.

---

## 🛠️ Используемые технологии

* **HTML5** — структурирование контента.
* **CSS3 / Flexbox** — кастомные стили, анимации и адаптивные медиа-запросы.
* **JavaScript (ES6)** — динамическое создание элементов интерфейса и логика рендеринга данных.
* **Bootstrap 5** — сетка, готовые классы для контейнеров, колонок и отступов.
* **FontAwesome** — иконки для навигации и корзины.
